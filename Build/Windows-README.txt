SHMTU Auth Windows 桌面版（Windows 10/11，64 位）

1. 将整个压缩包解压到一个可写的文件夹，例如桌面或 D:\shmtu-auth。
2. 双击 shmtu_auth_gui.exe。无需安装 Python 或 Docker。
3. 在“账号列表”中新建账号，填写校园网账号和密码并保存。
4. 在“认证”页面启动认证服务，程序会定时检查网络并尝试自动认证。
5. 关闭窗口默认隐藏到系统托盘；彻底退出请使用托盘菜单的“退出程序”。

程序同目录的 data、config、logs 文件夹保存账号、设置和日志，请妥善保留。
更新时先退出旧程序，再替换 exe，保留以上文件夹。
这是桌面 GUI，直接在窗口里设置账号，不需要网页管理密码或 18888 端口。
单文件首次启动需要解压依赖，请等待片刻。

项目源码及更新：https://github.com/yves5686x/shmtu-auth
